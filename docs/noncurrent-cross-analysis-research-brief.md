# 非應屆 × 學群 × 大學資料搜尋規格

## 目的

尋找可公開使用、可追溯來源的統計資料，用來回答以下問題：

1. 各大學的非應屆登記人數、錄取人數、錄取率與錄取生占比如何逐年變化？
2. 各學群的非應屆登記人數、錄取人數、錄取率與錄取生占比如何逐年變化？
3. 若資料足夠，進一步分析「學年度 × 大學 × 學群 × 應屆身分」。

本研究只需要匿名彙總統計，不需要也不可蒐集姓名、身分證字號、准考證號或其他個人資料。

## 研究範圍

- 主要年度：111–115 學年度。
- 延伸年度：110 學年度以前，有一致口徑時再納入。
- 主要管道：大學分發入學。
- 身分類別：官方定義的「應屆」與「非應屆」。
- 分析層級：大學、校系組、學群。
- 地理與設立別：可由本站既有教育部學校名錄補入，不必重複尋找。

不得把學測報名者、分科測驗報名者、分發入學登記者與分發錄取者視為同一母群。繁星推薦、申請入學、特殊選才與分發入學也必須分開標示。

## 最需要找到的資料

### P0：大學層級

每列至少是「學年度 × 招生管道 × 大學 × 應屆身分」，需要：

| 欄位 | 說明 |
|---|---|
| `academic_year` | 民國學年度，例如 115 |
| `admission_pathway` | 分發入學；若是其他管道必須另列 |
| `university_code` | 官方學校代碼；沒有時留空 |
| `university_name` | 當年度官方校名 |
| `current_status` | `應屆` 或 `非應屆` |
| `registered_count` | 完成分發登記人數 |
| `admitted_count` | 分發錄取人數 |
| `admission_rate` | `admitted_count / registered_count × 100`，可由本站重算 |
| `admitted_share` | 該校非應屆錄取人數占該校全部錄取人數 |
| `definition_note` | 原始文件對應屆／非應屆與母群的定義 |
| `source_url` | 可直接開啟的原始檔或網頁網址 |
| `source_page` | PDF 頁碼、表號或工作表名稱 |

如果只有錄取人數而沒有登記人數，仍可使用，但只能計算「錄取生中的非應屆占比」，不能宣稱是錄取率。

### P1：學群層級

每列至少是「學年度 × 招生管道 × 學群 × 應屆身分」，欄位與 P0 相同，另加：

| 欄位 | 說明 |
|---|---|
| `group_code` | 官方學群代碼；沒有時留空 |
| `group_name` | 官方學群名稱 |
| `group_system` | 使用哪一套學群分類及其發布單位 |
| `multi_group_rule` | 校系跨學群時是重複計入、分攤或只歸一類 |

必須找到官方學群分類定義。不同年度或不同機關若使用 18、19 或其他學群制度，不可直接合併。

### P2：校系組明細與學群對照

若沒有現成的學群非應屆統計，尋找下列兩份可連結的資料：

1. 「學年度 × 校系組 × 應屆身分」的登記／錄取彙總。
2. 「學年度 × 校系組 × 學群」的官方對照表。

校系組明細需要 `program_code`、`program_name`；學群對照應使用多對多 bridge table，一個校系跨兩個學群時保留兩列，不得強迫歸入單一學群。

## 官方來源優先順序

1. 大學考試入學分發委員會的年度統計、放榜簡報、附件、資料下載與新聞稿。
2. 教育部統計處、政府資料開放平臺、大專校院校務資訊公開平臺。
3. 政府研究報告、立法院或監察院引用且可追溯至主管機關的表格。
4. 各大學校務研究、招生分析或年報中的本校統計。
5. 新聞報導只用來找到原始資料，不作為最終數值來源。

已知入口：

- 分發委員會歷年資料：https://www.uac.edu.tw/downloads.htm
- 115 放榜統計：https://www2.uac.edu.tw/115data/115_result_presentation.pdf
- 115 各系組錄取表：https://www2.uac.edu.tw/115data/115_result_school_data.pdf
- 教育部資料開放平臺：https://data.gov.tw/
- 大專校院校務資訊公開：https://udb.moe.edu.tw/

除了目前網頁可見資料，也要檢查：PDF 附件、XLSX／CSV、新聞稿附件、網站原始連結、歷史站台、政府開放資料 API、學校年報及校務研究報告。

- `應屆 非應屆 校系 錄取 統計`
- `非應屆 學群 分發 錄取率`
- `錄取生 畢業年度 大學 分發`
- `大學分發 錄取生 基本資料分析表 校別`
- `大學分發 登記生 錄取生 應屆 非應屆 xlsx`
- `site:uac.edu.tw 非應屆 各校`
- `site:stats.moe.gov.tw 非應屆 大學 新生`
- `site:data.gov.tw 非應屆 大學 錄取`
- `site:edu.tw 校務研究 非應屆 新生`

搜尋時也應測試「重考生」關鍵字，但只有原始來源明確定義為非應屆時才能納入。

## 明確禁止的推估方式

- 不可把全體非應屆比例乘上各大學或學群錄取人數。
- 不可用校系名稱關鍵字自行猜測學群。
- 不可用出生年次直接判定應屆或非應屆。
- 不可用大一學生年齡、註冊率或在校人數代替分發錄取統計。
- 不可把「有報名考試」視為「完成分發登記」。
- 不可把分發錄取率稱為所有升學管道的上榜率。
- 不可將空值、`--`、抑制值或未公開值改成 0。
- 不可引用沒有原始連結、頁碼或表名的二手數字。

## 回傳檔案格式

找到資料後，請回傳以下檔案；沒有資料的欄位保留空值，不要猜測。

### `sources.csv`

```csv
source_id,title,publisher,academic_year,url,file_type,page_or_sheet,definition,accessed_at,notes
```

### `fact_noncurrent_admission.csv`

```csv
academic_year,admission_pathway,university_code,university_name,program_code,program_name,group_code,group_name,group_system,current_status,registered_count,admitted_count,source_id,source_page,notes
```

資料只有大學層級時，校系與學群欄位留空；只有學群層級時，大學與校系欄位留空。

### `bridge_program_group.csv`

```csv
academic_year,program_code,university_name,program_name,group_code,group_name,group_system,source_id,source_page,notes
```

### `research-notes.md`

內容至少包含：

- 查過哪些網站與文件。
- 找到與沒找到哪些層級。
- 各來源的應屆／非應屆定義。
- 年度間口徑是否改變。
- 是否存在跨學群重複計數。
- 任何無法解決的資料缺口。

原始 PDF／XLSX 不必重新上傳，但必須提供可下載的直接網址；若網址會失效，請記錄檔名與發布頁面。

## 驗收與加總檢查

各年度的大學或校系資料加總，應盡量與官方全體統計核對：

| 學年度 | 分發登記非應屆 | 分發錄取非應屆 | 全部錄取 |
|---|---:|---:|---:|
| 111 | 3,009 | 2,818 | 25,028 |
| 112 | 4,685 | 4,040 | 36,338 |
| 113 | 5,395 | 4,683 | 35,076 |
| 114 | 5,477 | 4,981 | 32,497 |
| 115 | 5,083 | 4,673 | 32,257 |

若學群允許一個校系跨屬多群，學群加總可能大於全體，必須明確記錄重複計數規則，不可強制調整成全體總數。

若數字無法對上，應列出差額與可能原因，例如外加名額、特殊生、缺漏學校、補分發、資料更新版本或定義不同。

## 找不到公開資料時

如果 P0–P2 都找不到，請改為尋找主管機關的資料申請窗口，並草擬申請內容。申請的最小資料表為：

```text
111–115 學年度大學分發入學之匿名彙總統計，欄位為：學年度、校系組代碼、學校名稱、校系組名稱、應屆／非應屆、完成登記人數、錄取人數。若有官方學群分類，請一併提供校系組與學群對照。
```

若因小樣本隱私考量無法提供校系層級，可依序退而請求「大學 × 應屆身分」與「學群 × 應屆身分」彙總；允許主管機關對小於特定門檻的儲存格作抑制，但須說明抑制規則。
