## MVP 實測結果

- 111–115 學測每年均發現 5 類附件：報名、缺考、原得總分與級分對照、級分分布、五標，共 25 份。
- 25 份實際內容均為 OLE Compound File `.xls`，可由 `xlrd 2.x` 解析。
- 111 年度頁面的附件標題是「各科級分人數分布表」，112–115 的頁面標題曾使用「各科級分人數百分比累計表」；檔案內表名與欄位一致，因此以標題別名探索、同一 adapter 解析。
- 五標檔含當年度及歷年資料，欄數會隨科目制度改變；parser 僅擷取附件所屬年度，並略過官方 `--` 欄位。
- 缺考檔的國文拆成「國綜」與「國寫」，不可擅自合併成單一科目；兩者分別保留。
- 報名表為橫向分段版型；總報名人數以最後一段「合計」欄與「合計」列交叉定位，不依賴固定儲存格。

## 存取與格式風險

- 官方網站憑證可由 Windows SChannel 驗證，但 Python 3.13+ 的 OpenSSL strict mode 會因憑證缺少 Subject Key Identifier 拒絕。下載器只移除 `VERIFY_X509_STRICT`，仍保留 CA 鏈與主機名驗證；沒有使用 `verify=False`。
- 發現與下載每次請求至少間隔 1.2 秒，並對 429／5xx 指數退避。既有檔案直接使用本機快取。
- 新年度若標題、工作表或欄位漂移，探索／parser／品質 gate 會失敗並留下清冊狀態，不會靜默略過。
